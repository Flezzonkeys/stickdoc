Optional tools
==============

smartctl.exe (smartmontools, GPL) for full SMART data:

1. Download the Windows installer from
   https://github.com/smartmontools/smartmontools/releases
   (file smartmontools-<version>.win32-setup.exe)
2. Install it on any Windows PC, or open the setup.exe with 7-Zip.
3. Copy bin\smartctl.exe (64-bit: bin64 if present) into this folder.

StickDoc finds it automatically: tools\smartctl.exe
